# Algorithms and Data Structures - Lab Portfolio

This repository contains implementation code and official laboratory reports for the **Algorithms and Data Structures** course (SWPS 2025). It serves as a comprehensive portfolio demonstrating practical mastery of core computer science concepts, memory management, and algorithmic problem-solving using **C**.

---

## Repository Structure

The repository is organized into modular subfolders (`lab1/` through `lab12/`), where each directory contains:
* **Source Code (`.c`)**: Clean, well-documented implementations adhering to standard C practices and thoroughly tested for exact execution outputs.
* **Laboratory Reports (`.pdf`)**: Official documentation detailing theoretical analysis, experimental results, and performance evaluations.

---

## Core Topics & Competencies Covered

Rather than isolated assignments, this collection spans a wide spectrum of fundamental data structures and advanced algorithmic paradigms:

* **Searching, Sorting & Complexity Analysis:** 
  * Implementation and performance benchmarking of Linear and Binary Searches.
  * Comparison of comparison-based sorting algorithms (Insertion Sort) and linear-time sorting (Counting Sort).
* **Linear & Non-Linear Data Structures:** 
  * Custom implementations of Circular Queues and Doubly Linked Lists with dynamic memory management.
  * Comprehensive Priority Queue and Heap operations (Min-Heap, Max-Heap, Heapify, Heap Sort, Key Decreasing/Increasing).
* **Graph Theory & Traversals:** 
  * Breadth-First Search (BFS) and Depth-First Search (DFS) for structural graph exploration.
  * Advanced graph applications including Strongly Connected Components (SCC), Prim's Minimum Spanning Tree (MST), and Disjoint-Set Data Structures (Union-Find with path compression and union by rank).
* **Algorithmic Design Paradigms:** 
  * **Dynamic Programming (DP):** Bottom-up approaches for Rod-Cutting, Matrix Chain Multiplication, and Longest Common Subsequence (LCS).
  * **Greedy Algorithms:** Activity Selection problem optimization.
  * **Greedy Data Compression:** Huffman Coding trees and prefix-code generation.
